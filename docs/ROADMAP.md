# Coverage plan

Goal: thousands of free integrations across banking, payments, social media, personal projects, PC and phone tools. This is not the current state.

Two connector classes: generated remote OpenAPI operations and explicitly configured local stdio MCP servers. Catalog categories are independent from pricing verification. Unknown or paid API access must not be advertised as free. Provider quotas, regional restrictions, identity requirements and terms need verification. A generated payment operation is never payment consent.

Local-device servers require installation on the user's device and explicit paths/permissions. A server running elsewhere does not connect to anybody's PC or phone. Phone integration is not implemented.
